Quy Chế Điểm Uy Tín UTC2Hand

Bảo vệ quyền lợi sinh viên và văn hóa trao đổi đồ dùng minh bạch tại UTC2.

Điểm ban đầu & Tối đa:
Tài khoản mới bắt đầu với 95 điểm, điểm tối đa là 100 điểm.
Dưới 90 điểm: Khóa quyền đặt cọc
Khi điểm uy tín < 90, bạn không được đặt cọc mua hàng để bảo đảm tính nghiêm túc của giao dịch.
Dưới 60 điểm: Khóa cả Đăng bán & Đặt cọc
Khi điểm uy tín < 60, tài khoản bị tạm khóa cả quyền đăng đồ pass và quyền đặt cọc.
Cách khôi phục và nâng điểm uy tín:
  • Đăng bán thành công: Khi bài đăng được duyệt thành công lên trang chính, bạn được cộng ngay +5 điểm uy tín.
  • Đổi xu nâng điểm: Dùng 50 Xu = +5 điểm uy tín (bấm nút "Đổi 50 Xu" ở trang Cá nhân).
  • Kiếm thêm xu: Chơi mini-game "Kéo Thả Săn Xu" để tích lũy xu miễn phí.

Cơ Sở Dữ Liệu Supabase Cloud (PostgreSQL)

Đồng bộ bài đăng, tin nhắn, đơn hàng và tài khoản sinh viên thời gian thực (Realtime) qua Supabase Cloud.

Trạng thái: Bộ nhớ đệm cục bộ (Sẵn sàng đồng bộ Cloud) Ping: -- ms
Nhập Supabase Project URL và Anon Key bên dưới để kết nối Database đám mây.
Lấy Key tại đây
SMTP / Gmail API
Hệ thống dùng máy chủ SMTP Gmail (hoặc Webhook Google Apps Script) để tự động gửi mã OTP xác thực và mã TimeMark đăng bài về Gmail.
* Xem tệp google_apps_script_mailer.js
2 Bước Hoàn Tất Kết Nối Supabase Cloud:
1. Tạo bảng dữ liệu: Mở SQL Editor dự án của bạn ➔ Bấm nút 📋 Sao Chép SQL Schema ở trên, dán vào và nhấn RUN.
2. Lấy API Key: Mở Trang API Keys của bạn ➔ Tìm mục anon public, copy chuỗi mã dán vào ô số 2 bên trên rồi bấm Lưu & kết nối.
Cách Khắc Phục Lỗi Hết Lượt Gửi Gmail (3 thư/giờ):
Gói miễn phí mặc định của Supabase giới hạn 3 thư/giờ. Bạn có 2 cách để gửi không giới hạn:
• Cách 1 (Khuyên dùng): Mở script.google.com ➔ Tạo mới và dán toàn bộ mã trong file google_apps_script_mailer.js ➔ Bấm Deploy (Web app, Anyone) ➔ Dán URL vào ô số 3 bên trên (Gửi 100-1500 thư/ngày hoàn toàn miễn phí bằng Gmail).
• Cách 2: Vào Supabase Auth Settings ➔ Bật Enable Custom SMTP (dùng smtp.gmail.com port 587) để Supabase tự gửi thư trực tiếp không giới hạn.
