Phân Bổ Kiến Trúc 3 Môn: DSA - OOP - Thiết Kế Web

Môn Cấu Trúc Dữ Liệu (DSA)
  • 1. Cây tiền tố (Trie): Tìm kiếm tức thì từ khóa, mã môn học với độ phức tạp $O(L)$ thay vì quét database $O(N)$.
  • 2. Cây AVL (Cân bằng): Đánh chỉ mục khoảng giá để lọc sản phẩm cực nhanh trong $O(\log N + K)$.
  • 3. Min-Heap (Priority Queue): Quét các bài viết quá 14 ngày (TTL) để tự động hủy bài cũ/hết hạn.
Môn Hướng Đối Tượng (OOP)
  • 1. Kế thừa & Đa hình: `ItemListing` trừu tượng chia thành `TextbookListing`, `DeviceListing`, `ApplianceListing`.
  • 2. State Pattern: Vòng đời bài đăng (`Available` $\rightarrow$ `Inspecting` $\rightarrow$ `Sold`).
  • 3. Observer Pattern: Tự động bắn thông báo khi có người đăng món đồ thuộc mã môn sinh viên đang theo dõi.
Môn Thiết Kế Web
  • 1. Giao diện Responsive: Tương thích hoàn hảo từ Mobile đến Laptop bằng Tailwind CSS.
  • 2. Xử lý bất đồng bộ: Debounce 250ms cho thanh tìm kiếm, fetch API mượt mà không load lại trang.
  • 3. UX Sinh viên: Badge TimeMark, đếm ngược giữ đồ và bản đồ điểm hẹn trong khuôn viên.
