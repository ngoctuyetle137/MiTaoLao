Báo Cáo Kiến Trúc Hệ Thống UniPass UTC2

Phân tích chi tiết các Cấu trúc dữ liệu tự xây dựng độc lập và Mô hình Hướng đối tượng (Design Patterns)

1. Các Module Cấu Trúc Dữ Liệu Tự Xây Dựng Độc Lập (DSA)

1. Trie (Prefix Tree with Frequency) O(L)

Tự cài đặt lớp `TrieNode` và `Trie` để gợi ý tức thì khi sinh viên gõ tên giáo trình (VL101, Casio, Toán, Nồi cơm...). Xếp hạng gợi ý theo tần suất tìm kiếm `frequency`.

2. AVL Tree (Cây Tự Cân Bằng) O(log N + K)

Tự cài đặt `AVLTreeNode` với các phép xoay Left/Right rotation. Module `rangeSearch(minPrice, maxPrice)` độc lập lọc sản phẩm theo khoảng giá siêu tốc in-memory.

3. Max-Heap (Priority Queue Shopee) O(N log K)

Tự code thuật toán Heapify Up/Down để tính trọng số gợi ý sản phẩm phù hợp nhất (Shopee-style) dựa trên Uy tín x 0.4 + Views x 0.3 + Khoảng cách x 0.3.

4. Campus Graph & Dijkstra O(E + V log V)

Đồ thị vô hướng mô phỏng các mốc địa lý thực tế tại ĐH UTC2 (Cổng 1, KTX Cỏ May, Thư viện, Giảng đường A4...). Tính khoảng cách ngắn nhất để sinh viên nhận đồ.

2. Biểu Đồ Lớp (Class Diagram) & 4 Design Patterns Kinh Điển 

+---------------------------------------------------------------------------------+
|                                 CLASS DIAGRAM                                   |
+---------------------------------------------------------------------------------+
| <> Product                                                            |
| - id, title, price, category, sellerId, sellerName, sellerReputation            |
| - location, distance, timeMarkCode, imageUrl, daysRemaining, status             |
| + calculateDeposit(): number                                                    |
| + getCategoryBadge(): string                                                    |
+---------------------------------------------------------------------------------+
            ^                             ^                              ^
            |                             |                              |
+----------------------+     +-------------------------+     +--------------------+
| BookProduct          |     | TechProduct             |     | LivingProduct      |
| - courseCode (VL101) |     | - warrantyMonths        |     | - roomType         |
| - publisher          |     | - conditionPercentage   |     | - isPortable       |
+----------------------+     +-------------------------+     +--------------------+
            ^
            |  (Uses Factory Pattern)
+---------------------------------------------------------------------------------+
| ProductFactory: createProduct(category, data): Product                          |
| Singleton: UniPassDatabase (getInstance, products, trie, avlTree, maxHeap)      |
| Strategy: DepositContext -> StandardDepositStrategy | HighReputationStrategy    |
| Observer: EventManager -> notifySubscribers(TRADE_COMPLETED, POST_EXPIRED)     |
+---------------------------------------------------------------------------------+
Singleton Pattern

Đảm bảo 1 phiên bản `UniPassDatabase` duy nhất quản lý in-memory store và cache đồng bộ.

Factory Pattern

`ProductFactory` khởi tạo đúng đối tượng Book, Tech hoặc Living dựa trên danh mục.

Strategy Pattern

Đổi linh hoạt công thức tính cọc dựa trên điểm uy tín sinh viên và trừ xu UniCoins.

Observer Pattern

`EventManager` tự động bắn thông báo khi có cọc mới, hết hạn bài đăng, hoặc nhận đồ xong.
